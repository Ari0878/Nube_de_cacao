Generar Respaldo

Selecciona el tipo de respaldo y el formato de descarga

1. Tipo de Respaldo
Completo

Respalda todos los registros de la base de datos. Recomendado para respaldos periódicos completos.

Todos los registros
Incremental

Solo registros nuevos desde el último respaldo. Más rápido y ocupa menos espacio.

Solo cambios nuevos
Diferencial

Cambios desde el último respaldo completo. Balance entre completo e incremental.

Desde último completo
2. Formato de Descarga

El respaldo se generará de forma segura y se descargará automáticamente

¿Qué tipo elegir?
  • Completo: Para respaldos semanales o mensuales
  • Incremental: Para respaldos diarios automáticos
  • Diferencial: Para recuperación rápida de datos recientes
Recomendaciones
  • Guarda los respaldos en ubicaciones seguras
  • Realiza respaldos completos al menos una vez por semana
  • Verifica periódicamente que los respaldos sean válidos
